## Teaching structure

1. **Question:** State exactly what the viewer will understand.
2. **Simple explanation:** Define the concept in plain language.
3. **Step-by-step breakdown:** Explain the process or rule in sequence.
4. **Visual demonstration:** Use accurate diagrams, demonstrations or illustrative clips.
5. **Common misunderstanding:** Correct one misconception only if supported.
6. **Recap:** Repeat the practical takeaway.

## Accuracy requirements

- Check current rules with the relevant governing body or authoritative source.
- State the level, age group or competition context when rules differ.
- Do not present general training information as individual medical or coaching advice.
- Use qualified review for potentially risky physical instruction.
- Never demonstrate unsafe technique as recommended practice.

## Visual style

Use clean, high-contrast diagrams and accurate field/court layouts. Add labels and arrows in post-production, not as generated text. Make each visual explain one point.
