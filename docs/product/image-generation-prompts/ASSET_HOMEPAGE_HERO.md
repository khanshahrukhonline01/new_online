# Asset prompt — Homepage hero

**Inherits:** [Master AI Image Generation Prompt](../MASTER_AI_IMAGE_GENERATION_PROMPT.md)

## Prompt

Create a premium, photorealistic **homepage hero background** for KhelGrid.

- **Sport:** [SPORT]
- **Moment:** [ONE clear, instantly understandable sporting action]
- **Environment:** [STADIUM / GROUND / ARENA / COURT]
- **Layout:** Wide 16:9 landscape composition, preferably 1920 × 1080 or higher. Keep the key athlete/action inside the central safe area so desktop, tablet and mobile crops remain usable.
- **Text-safe area:** Reserve uncluttered negative space on [LEFT / RIGHT] for HTML headline and buttons. Do not generate text.
- **Visual hierarchy:** One clear primary action, supporting environment and restrained background detail.
- **Brand colour:** Subtle deep navy and emerald accents; preserve natural sporting colours.
- **Output:** Clean background image only, no UI, no logo, no title, no CTA, no border.

Generate a single coherent photograph, not a collage or multi-panel design. Prepare a separate mobile crop or alternate composition if the desktop master cannot crop safely.
