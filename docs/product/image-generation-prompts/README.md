## How to use this library

1. Select the sport and/or asset type.
2. Fill in the bracketed fields with the intended action, environment, crop and usage.
3. Combine the selected prompt with the [Master AI Image Generation Prompt](../MASTER_AI_IMAGE_GENERATION_PROMPT.md).
4. Generate the image without text or third-party branding.
5. Review sport accuracy, visual quality, responsive crops and rights evidence.
6. Record the original output and metadata in the asset manifest.
7. Keep the asset pending until visual and rights approval are complete.

## Naming convention

Use lowercase descriptive names and include sport or purpose, for example:

- `hero-cricket-stadium.webp`
- `sport-card-badminton.webp`
- `venue-football-turf.webp`
- `editorial-athletics-training.webp`

Do not overwrite an approved asset with a new generation. Create a new version and update the manifest after review.

## Governance

These are prompt templates, not approval to publish. A generated image is not automatically exclusive, copyright-protected, non-infringing or production-approved. Follow the master standard and asset rights workflow for every output.
