# Asset prompt — Opportunity and trial banners

**Inherits:** [Master AI Image Generation Prompt](../MASTER_AI_IMAGE_GENERATION_PROMPT.md)

## Prompt

Create an original, photorealistic sports image for a KhelGrid **[TRIAL / CAMP / SCHOLARSHIP / COMBINE / ATHLETE OPPORTUNITY]** page.

- **Sport and discipline:** [SPORT]
- **Athlete stage:** [YOUTH / DEVELOPMENT / ADULT / OPEN], represented inclusively and without implying a real participant.
- **Action:** [TRAINING / SKILL DEMONSTRATION / FITNESS TEST / TEAM DRILL]
- **Environment:** Generic, plausible training facility; do not depict a named real event or venue.
- **Composition:** Wide landscape banner with an uncluttered text-safe region for page heading and filters.
- **Tone:** Encouraging, credible and athlete-centred; avoid exaggerated victory or guaranteed-selection imagery.
- **Brand treatment:** Restrained navy and emerald accents; no logos, dates, application deadlines, selection claims or event names.

The image is illustrative only. It must not be presented as evidence that a specific trial, camp, scholarship or opening exists.
