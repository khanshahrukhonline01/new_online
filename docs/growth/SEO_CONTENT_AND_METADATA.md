# SEO, Structured Data and Content Quality

**Status:** Draft

Use crawlable canonical URLs, meaningful titles/descriptions, sitemap and robots rules, sensible redirects and a consistent URL policy. Include only public, useful, canonical pages in the sitemap; exclude private, test, duplicate and error routes.

Use structured data only when page content qualifies. It must match visible content; never invent ratings, prices, availability, event status or organization details.

Opportunity pages should provide useful sourced information and link to the original publisher. Avoid thin mass-generated pages, duplicates and expired opportunities presented as current. Link sports to related opportunities and venues only when real relationships exist.

Before release, validate sitemap, canonical tags, metadata, robots, structured data, internal links and representative mobile pages. Monitor indexing without promising rankings.
