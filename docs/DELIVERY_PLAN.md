# Delivery plan

1. Foundation: application shell, type checks, linting, tests, and CI.
2. Design system: navigation, accessible components, forms, and loading/empty/error states.
3. Data foundation: Supabase configuration, migrations, RLS, and typed access layer.
4. Core journeys: profiles, verified opportunities, search, applications, and bookings.
5. Live sports: evaluate authorized providers and integrate only verified coverage.
6. Trust and monetization: moderation, privacy/terms, analytics, and policy-compliant ads.
7. Release readiness: end-to-end tests, security review, performance, SEO, preview deployment, and explicit owner approval.

A stage is complete only when acceptance criteria and test evidence are recorded. Mock data must never be presented as a live service.
