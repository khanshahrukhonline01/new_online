# Sports CV

**Status:** Planned specification

## Core journey
Collect athlete-approved details, validate them, preview a clear sports CV and export a PDF or shareable profile only when that sharing behaviour is explicitly chosen.

## Data minimization
Explain which fields are required and optional. Avoid collecting sensitive information without a clear need. Make local-only versus server storage explicit. Never transmit CV data silently or include it in analytics/logs.

## Output quality
Support education, sport, position/event, achievements, training, competition history and coach references where appropriate. Do not imply achievements or certifications were independently verified unless the verification process supports that claim.

## Accessibility and languages
Use labelled fields, accessible validation and keyboard support. Plan translated labels and instructions separately from user-entered content; review translated PDFs before claiming support.

## Acceptance
Validate fields, handle empty and long content, produce a readable PDF, explain storage/retention, and test that personal data is not sent to an unapproved service.
